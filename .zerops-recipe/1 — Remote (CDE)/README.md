# Deck Renderer — Remote Environment

This is a remote (CDE) environment for [Deck Renderer (info + deploy)](https://app.zerops.io/recipes/deck-renderer?environment=remote-cde) recipe on [Zerops](https://zerops.io).

<!-- #ZEROPS_EXTRACT_START:intro# -->
**Remote (CDE)** environment lets a developer build the project **inside Zerops**
via SSH — Vite on `frontenddev`, the API on `apidev`, Chromium worker on
`workerdev`, plus stage services and hobby Postgres / Valkey / NATS.
