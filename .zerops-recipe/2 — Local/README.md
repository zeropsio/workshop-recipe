# Deck Renderer — Local Environment

This is a local environment for [Deck Renderer (info + deploy)](https://app.zerops.io/recipes/deck-renderer?environment=local) recipe on [Zerops](https://zerops.io).

<!-- #ZEROPS_EXTRACT_START:intro# -->
**Local** environment keeps PostgreSQL, Valkey, NATS, and the Chromium
worker on Zerops. Use zCLI VPN to reach `db`, `queue`, and `cache` from
a laptop, or open the staged SPA and API on their subdomains.
