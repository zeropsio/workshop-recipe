# Deck Renderer Recipe

<!-- #ZEROPS_EXTRACT_START:intro# -->
Markdown-to-slide pipeline on [Zerops](https://zerops.io): a [React](https://react.dev) + [Vite](https://vite.dev) SPA, a Node API with WebSocket progress, and Chromium workers behind [NATS](https://nats.io), with PostgreSQL and Valkey. Horizontal worker scale is the point of the recipe.
